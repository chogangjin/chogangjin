# chogangjin 🎮 게임 개발

**Unity 게임 UI · 게임 진행 저장 · DirectX 11 그래픽스**


## 🕹️ HeroInfluence

Unity 팀 프로젝트에서 **타이틀과 로비 UI, 게임 저장, 채팅 UI**를 담당했습니다.

| 플레이어가 하는 일 | 담당한 부분 |
| --- | --- |
| 게임을 시작하고 로비에 들어가기 | 타이틀 · 로비 UI |
| 이전에 플레이한 지점에서 이어가기 | 게임 진행 데이터 저장 |
| 게임 안에서 대화 읽기 | 채팅 UI |

[HeroInfluence 팀 저장소 ↗](https://github.com/TeamNorthernSky/HeroInfluence)

## 🛠️ AliceRenderer

DirectX 11 기반 3D 게임 엔진입니다. 엔진의 전체 구조에서 시작해 한 프레임의 업데이트와 렌더링 흐름을 따라갈 수 있습니다.
